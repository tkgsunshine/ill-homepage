Claude CodeでX（旧Twitter）投稿を自動化する自社運用事例

Claude CodeX（旧Twitter）運用投稿文自動生成GitHub連携
クライアント業種自社運用（Ill inc.）／ SNS・コンテンツ配信
制作期間運用しながら継続改善（自社内製）
提供スコープ投稿文の生成ルール設計、コラム連動の配信フロー構築、承認・停止ルールの設計
結論・要点

Claude Codeに「書いてよい事実」のルールを渡し、公開コラムを入力にX投稿文を生成させています。価格・事例に触れる内容は人が確認し、自動投稿は段階的に有効化する運用です。

1. 課題と背景：SNS発信は人手に頼ると止まる

Ill（イル）株式会社は、SEOコラムを1日2回、GitHub Actionsで自動公開しています。公開された記事を検索経由だけで届けるのではなく、X（旧Twitter）でも発信したいと考えていましたが、記事ごとに投稿文を考えて手動で投稿する運用は、忙しくなると真っ先に止まります。

  • 継続の壁: 公開のたびに投稿文を作る作業は小さいが、毎日積み重なると負担になる。
  • トーンのブレ: 担当者や時期で文体・訴求が変わり、AI開発会社としての見え方が揃わない。
  • 事実に反する表現のリスク: 実績や価格を盛った投稿は信頼を損なう。書いてよい事実の範囲を固定する必要があった。

つまり必要だったのは「投稿を自動で作る」ことだけでなく、何を書いてよいかを機械が守れる形にすることでした。

2. Claude CodeによるX投稿自動化の仕組み

基本の流れは次のとおりです。

  1. コラムが公開される: 編集カレンダーの未公開分を、GitHub Actionsが朝夕に公開する（既存の自動公開パイプライン）。
  2. 記事の要点とURLを取り出す: タイトル・結論・URLなど、投稿に必要な情報を公開記事から取得する。
  3. Claude Codeが投稿文を生成する: リポジトリ内のルール文書（書いてよい事実・禁止事項）を読み込んだ上で、投稿文を作る。
  4. 確認して投稿する: 価格・事例に触れる内容は人が確認する。自動投稿の有効化と停止は人が決める。

ルール文書は、事業の方針（新規開発に特化している、MVPの価格帯と納期の範囲など）をまとめたもので、AIが毎回同じ前提で書くための土台です。

3. AIに書かせてよい内容・書かせない内容

自動化で最も重要なのは、禁止事項を先に決めることです。Ill（イル）株式会社では、次のように線を引いています。

区分内容
書いてよい公開済みコラムの要点、開発体制（Claude Code・ベトナムのオフショア）、MVPの価格帯と納期の範囲、記事へのリンク
書かない契約条件（支払い条件・保証期間・単価）、根拠のない実績・数値、存在しないSNSアカウントやプロフィール
人が確認価格や事例に触れる投稿、新しい訴求の追加、自動投稿の有効化・停止

この表をそのままルール文書に書き、AIに読ませています。人間の担当者にも同じ表を渡せるため、運用が属人化しません。

4. 段階的に自動化を進める：下書き生成から自動投稿へ

外部に公開される投稿は、いったん出ると取り消しにくい性質があります。そこで、いきなり完全自動にせず、次の順で進めるのが安全です。

  1. 下書き生成のみ: AIが投稿文を作り、人が内容を見て投稿する。
  2. 低リスクな投稿から自動化: 記事の要点とリンクだけの投稿など、確認の必要が少ないものを自動投稿にする。
  3. 停止の手順を用意: 問題が出たときに止められるよう、停止の手順と責任者を決めておく。

Ill（イル）株式会社でも、外部への自動投稿の有効化は人が判断する方針です。

5. 導入効果と、運用で気をつけた点

コラム公開から投稿までの手作業が減り、発信が途切れにくい状態になりました。ルール文書を書き換えるだけで、投稿全体のトーンや禁止事項を一括で変更できる点も、人手運用にはない利点です。変更はGitの履歴に残るため、いつ誰が何を変えたかも追えます。

一方で、投稿の最終的な責任は人が持つ前提を崩していません。AIの出力を鵜呑みにせず、数値や実績は根拠のあるものだけを使う運用を守っています。

6. 新規開発・MVPへの応用

自社の運用で実証した「AIに役割を持たせ、人は承認する」型は、新規開発のMVPにもそのまま使えます。

新規事業の立ち上げ初期は、発信に割ける人手が少ないのが普通です。「コンテンツを入力に、ルールに沿って投稿文を作る」仕組みは、小さく作って早く試せます。Ill（イル）株式会社は、Claude Codeを使ったAI駆動開発とベトナムのオフショアチームで、MVPを10万〜100万円・数日〜数週間から開発しています（要件により個別見積もり）。

よくある質問（FAQ）

Q. Claude CodeによるSNS自動投稿は新規事業にも使えますか？

A. はい。新規事業の立ち上げ初期は発信の人手が足りないため、コンテンツ連動の投稿生成は相性が良い使い方です。Ill（イル）株式会社では、MVP開発とあわせた運用設計のご相談も承っています。

Q. AIが誤った内容を投稿するリスクはどう抑えますか？

A. 書いてよい事実をルール文書に固定し、価格や実績に触れる内容は人が確認する運用にします。自動投稿の有効化・停止も人が決められる設計にします。

Q. 最初から完全自動にしても問題ありませんか？

A. おすすめしません。まずは下書き生成のみで運用して出力の傾向を確認し、低リスクな投稿から段階的に自動化するのが安全です。
