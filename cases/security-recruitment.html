求人・マッチング / クラウド移行

警備求人マッチングサイトのSPA全面刷新＆GCP・Cloudflare移行で月額費用60%削減

Next.js (SPA) NestJS (TypeScript) Google Cloud (Cloud Run) Cloudflare WAF PostgreSQL
クライアント業種 警備・ビルメンテナンス / 人材求人メディア
開発期間 約3.5ヶ月
提供スコープ 要件定義、Next.js/NestJS開発、GCPインフラ移行、Cloudflareセキュリティ設計、SEO最適化

1. 課題と導入前のボトルネック

月間数十万PVを抱える警備業界特化型の求人ポータルサイトにおいて、以下の3つの深刻な課題が事業拡大のボトルネックとなっていました。
  • レガシー技術とレスポンス遅延: Apache + nginx、CakePHP（従来型MVC）による古い構成で、検索絞り込みや画面遷移のレスポンスが重く離脱が多発。
  • 高額なインフラ月額費用（月100万円超）: オンプレミス（IDフロンティア）とAWSが複雑に混在し、過剰なEC2/RDSインスタンス設計で月額100万円以上を浪費。
  • セキュリティ対策の未整備: WAFやBot対策、DDoS対策が未導入であり、悪質なスクレイピングや不正アクセスによるサーバー高負荷リスクを抱えていた。
  • 旧態依然としたUIデザイン: PC前提の古いフォームUIでスマートフォンからの求人応募完了率（CVR）が低迷していた。

2. Ill（イル）株式会社による設計・開発アプローチ

Ill（イル）株式会社 では、完全ヘッドレスなSPA構成とサーバーレスGCPインフラを設計し、全面的なリプレイスを敢行しました。
  • Next.js + NestJS による完全SPAアーキテクチャ刷新: フロントエンドにNext.js（SPA）、バックエンドにNestJS（TypeScript）を採用し、画面再読み込みのないシームレスな求人検索体験を実現。
  • GCP（Google Cloud）への全面集約とサーバーレス最適化: Cloud RunとCloud SQL（PostgreSQL）を中核とした構成へ移行し、トラフィックに連動する最適課金モデルへシフト。
  • Cloudflare による鉄壁のセキュリティとエッジ配信: Cloudflare WAF、Bot Management、DDoS防御を最前線に配備。悪質Botをエッジで遮断しつつ、求人データを高速キャッシュ配信。
  • モバイルファーストなUI/UXフルリニューアル: 警備求職者の行動特性を徹底分析し、エリア・日払い・未経験等のワンタップ絞り込みや超軽量応募フォームを実装。

3. 導入効果とビジネスインパクト（ROI実績）

インフラ月額費用を100万円超から40万円台（約60%削減 / 年間700万円以上のコスト削減）へ劇的圧縮。
さらにSPA化とCDNキャッシュによりページ表示速度が約3.5倍高速化し、直帰率の大幅低減とスマートフォン経由の応募CVR（コンバージョン率）28%向上を達成しました。

よくある質問（FAQ）

Q. 数十万件の既存求人データや会員データの移行は安全に行えますか？

A. はい。新旧DBのデータマッピングと検証スクリプトを作成し、暗号化パスワードの移行を含めて欠損ゼロで安全に切り替えます。

Q. リニューアルによる検索順位（SEO）の下落を防ぐ対策は可能ですか？

A. はい。全URLの301リダイレクト設計、内部リンク最適化、構造化データ（JobPosting）の完全継承を実施し、SEO評価を損なわずにリニューアルいたします。
