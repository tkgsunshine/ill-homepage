求人・マッチング / クラウド移行

警備業界特化型 求人マッチングサイトのフルリニューアル＆GCP移行

Next.js (SPA) NestJS (TypeScript) Google Cloud (GCP) Cloudflare (WAF/DDoS) PostgreSQL

課題・背景

月間数十万PVを抱える警備業界特化型の求人ポータルサイトにおいて、以下の3つの深刻な課題が事業拡大のボトルネックとなっていました。

  • レガシー技術とレスポンス遅延: Apache + nginx、CakePHP（従来型MVC）による古いサーバーサイドレンダリング構成で、検索絞り込みやページ遷移時のレスポンスが重く、モバイル求職者の離脱原因になっていた。
  • 高額なインフラ月額費用（月100万円超）: オンプレミス（IDフロンティア）とAWSが複雑に混在し、過剰なEC2/RDSインスタンス設計によってインフラ運用維持費が月額100万円を超過していた。
  • セキュリティ対策の未整備: WAFやBot対策、DDoS対策が未導入であり、悪質なスクレイピングや不正アクセスによるサーバー高負荷リスクを抱えていた。
  • 旧態依然としたUIデザイン: PC前提の古いフォームUIでスマートフォンからの求人応募完了率（CVR）が低迷していた。

提供したアプローチ・機能

  • Next.js + NestJS によるSPAアーキテクチャ刷新: フロントエンドにNext.js（SPA）、バックエンドにNestJS（TypeScript）を採用し、完全ヘッドレス・API駆動のモダンアーキテクチャへ全面再構築。画面遷移のないシームレスな求人検索体験を実現。
  • GCP（Google Cloud）への全面移行と最適化: Cloud RunとCloud SQL（PostgreSQL）を中核としたサーバーレス・オートスケール構成へ移行。過剰な常時稼働インスタンスを排除し、アクセス増減に連動する最適課金モデルへシフト。
  • Cloudflare による鉄壁のセキュリティとCDN配信: Cloudflare WAF、Bot Management、DDoS防御を最前線に導入。悪質なクローラーや攻撃をエッジで完全遮断しつつ、静的アセットと求人キャッシュを高速エッジ配信。
  • モバイルファーストなUI/UXフルリニューアル: 警備求職者の行動特性を徹底分析し、エリア・日払い・未経験等のワンタップ絞り込みや、LINE連携を含む超軽量応募フォームを設計・実装。

Illの強みと効果

要件定義からフロントエンド・バックエンド開発、インフラ移行設計、Cloudflareセキュリティ導入まで一貫対応。
その結果、月額インフラ費用を100万円超から半分以下の40万円台（約60%削減 / 年間700万円以上のコスト削減）へ劇的に圧縮しました。
さらにSPA化とCDNキャッシュによりページ表示速度が約3.5倍高速化し、直帰率の大幅低減とスマートフォン経由の応募CVR（コンバージョン率）28%向上を達成しました。
