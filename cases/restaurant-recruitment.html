飲食店舗とスキマ時間ワーカーを即時マッチングするスポットバイトプラットフォーム

React Native Firebase / Google Cloud Node.js Stripe Payouts Google Maps API
クライアント業種 飲食・レストラン / ギグワーク・短期人材
開発期間 約3.5ヶ月
提供スコープ モバイルアプリ（iOS/Android）、店舗向けWebダッシュボード、即時送金API連携、位置情報検索

1. 課題と導入前のボトルネック

飲食業界における慢性的な人手不足とドタキャン（急な欠員）に対し、従来の求人広告では数日〜数週間の募集タイムラグがあり即時対応ができませんでした。
  • 当日欠員への即時補充手段の欠如: 繁忙日の直前キャンセルが発生した際、当日中にスタッフを確保する手段がなかった。
  • 給与支払い・労務手続きの手間: 短期・単発バイトの給与計算、源泉徴収、即日振込を手作業で行う労務管理が困難。
  • 無断欠勤（バックレ）やスキルミスマッチのリスク: 応募者の信頼性や過去の勤務評価を事前に確認できる仕組みがなかった。

2. Ill（イル）株式会社による設計・開発アプローチ

Ill（イル）株式会社 では、位置情報とリアルタイムプッシュ通知を駆使した最短10分マッチングプラットフォームを開発しました。
  • マップ連動の即日スポット求人募集: 店舗が募集人数・時給・勤務時間を入力するだけで、近隣3km以内の適格ワーカーへ一斉プッシュ通知。
  • 面接不要の即時マッチング & チェックイン機能: QRコードスキャンによる勤務開始・終了打刻で、正確な実働時間を自動記録。
  • 給与即時振込（リアルタイムウォレット）連携: Stripe Payouts / 銀行APIと連携し、退勤ボタン押下と同時にワーカーの銀行口座へ給与を即時反映。
  • 相互評価レーティング & ペナルティシステム: 店舗とワーカーの双方評価システムを実装し、無断キャンセル時の自動利用停止ロジックを導入。

3. 導入効果とビジネスインパクト（ROI実績）

リリース後、当日の欠員補充マッチング成功率89%を達成。
店舗側の求人広告費を従来の月平均15万円から実稼働分のみの成果報酬へ削減し、飲食チェーン約350店舗に導入されました。

よくある質問（FAQ）

Q. 労務管理（雇用契約書の自動締結や源泉徴収票発行）もシステム内で完結できますか？

A. はい。マッチング成立時に労働条件通知書・雇用契約を電磁的に自動締結し、年末調整・源泉徴収票データのエクスポートに対応しています。

Q. 位置情報（GPS）を活用した不正打刻防止は可能ですか？

A. はい。店舗指定半径内でのみQRコードスキャン打刻を許可するジオフェンシング技術により、不正打刻を完全防止します。
