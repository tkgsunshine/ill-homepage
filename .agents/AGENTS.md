# Ill inc. SEO and Lead-Generation Strategy

This document outlines the core SEO guidelines and strategies for creating columns, case studies, and index updates. Antigravity must follow these rules without exception.

## 1. High-Value Keyword Targeting (S/A-Class Priority)
Avoid generic, highly competitive "what is" keywords (e.g., "ChatGPTとは"). Instead, focus on:
*   **High-Intent / Conversion Keywords (S-class)**:
    *   `システム開発 費用` (System development costs)
    *   `システム開発会社 選び方` (How to choose a development vendor)
    *   `AI開発 費用` (AI development costs)
    *   `ChatGPT API料金` / `OpenAI API料金` (API pricing structures)
    *   `AIチャットボット 開発` (AI Chatbot development)
    *   `RAG 開発` / `AIエージェント 開発` (RAG / Agent development)
*   **Executive & Management Keywords (A-class)**:
    *   `AI導入 失敗事例` / `AI導入費用`
    *   `DX 失敗例` / `システム化できる業務`
    *   `AIで経理を自動化` / `AIで営業を自動化`

## 2. Strong E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness)
*   Write from the perspective of an actual software and AI development company (**"開発会社だから書けること"**).
*   Avoid generic descriptions; ground content in practical project experiences (e.g., token usage optimization, custom Vector Database setup, agile release cycles, lab contract negotiations).
*   Integrate real-world case studies and internal expertise references.

## 3. High-Conversion Lead Flow (CV / CTA Design)
At the bottom of informational articles, implement structured, actionable Call-to-Action (CTA) blocks with precise customer targeting instead of vague sign-offs.
*   **Targeting Box**: "こんな企業様におすすめです" (e.g., companies with 30+ employees, large volumes of PDFs/internal documents, high query volume, seeking mock-ups).
*   **Clear Next Steps**: Dedicated buttons linking to the contact form (`../index.html#contact`) or cases index (`../cases/`).

## 4. Comprehensive Length & Rich Visuals
*   **Word Count**: Target **3,000 to 6,000 Japanese characters** per article to ensure deep coverage of topics.
*   **Visual Assets & Tables**:
    *   Include structured HTML comparison tables (`.article-table-wrapper` / `.article-table`).
    *   Ensure each article features clear process steps, lists, and a clean, responsive layout.

## 5. Strategic Interlinking
Create a spiderweb of internal links. Guide users from informational keywords to technical deep-dives, then cost breakdowns, and finally the inquiry flow.
*   *Example*: `RAG 開発` -> `OpenAI API 料金` -> `システム開発 費用` -> `問い合わせ`
